#### BUY Signals
- **Moving Averages**: 3MA > 5MA > 15MA > 25MA (aligned upwards)
- **GHL Indicator**: Lime bars
- **QTI Indicator**: Lime bars

- **Moving Averages**: 3MA < 5MA < 15MA < 25MA (aligned downwards)
- **GHL Indicator**: Red bars
- **QTI Indicator**: Red bars

### Option 3: Implement Simple GHL Logic

The GHL (Green High Low) can be approximated:
- Green bar: Close > Open
- Red bar: Close < Open

Replace `GetGHLSignal()` with:

```mql4

{
   double open = iOpen(Symbol(), PERIOD_CURRENT, shift);
   double close = iClose(Symbol(), PERIOD_CURRENT, shift);
   return (close > open); // True = lime/green, False = red
}
```
